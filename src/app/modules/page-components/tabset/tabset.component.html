What is a Tabset?
Tabset is a flexible container that allows you to organize any content in tabs. This makes switching between sections quick and user-friendly.

Tabs are a great way to structure your interface and keep all key actions within reach. You can add, search, or view extra details without navigating away from the current page.

The mefdev-tabset component supports custom animations, nested routing, any kind of content (forms, lists, charts, etc.), and a simple API for customization. You can change appearance, tab type, placement, and integrate your own components.

  • Animated tab transitions
  • Flexible placement and style
  • Supports forms, lists, buttons, selects, switches, and more
  • Customizable for any content
